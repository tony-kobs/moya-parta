## 1. Суть продукту

Не електронний щоденник. Цифровий клас навколо дитини:

> «У кожного є своя парта. У кожного є своє місце в класі.»

Фокус: дитина → клас → друзі → творчість → навчання → гра → маленькі перемоги.  
Без рейтингів між дітьми, без followers, без токсичної конкуренції.

---

## 2. Хто в екосистемі (актуальне рішення)

| Роль | Статус | Що робить |
|------|--------|-----------|
| **Учитель** | є | реєструється, створює клас, дає код/лінк, завдання і тести, перевіряє роботи, події, адмін дошки + розклад, daily/weekly, чат |
| **Учень** | є | заходить за кодом, парта, клас (стрічка+розклад), своя дошка, чат, навчання, periodic, перемоги |
| **Батьки** | **немає кабінету** | лише допомагають дитині на вході (варіант **A**) |
| **School Admin** | **немає** | не потрібен, поки вчитель сам володіє класом |

### Ланцюг доступу (канон)

```
Вчитель реєструється (/register)
  → створює клас
  → отримує код + /join/КОД
  → дає учням (або батькам, щоб допомогли)
Учень/з допомогою батька заходить за кодом
  → реєструється
  → onboarding
  → Моя парта
```

### Спілкування (канон)

- **Дошка класу:** пости лише **вчитель** (створити / редагувати / видалити / закріпити / приховати)
- Учні на дошці класу лише **реагують**
- **Моя дошка** учня — особисті пости (клас їх не бачить)
- Вкладка **Розклад уроків** (тиждень Пн–Пт) на дошці вчителя і в «Мій клас» учня
- **Чат класу** — усі учні + учитель
- **Особисті повідомлення** — учень ↔ однокласник, учень ↔ учитель (лише свій клас)

## 3. Структура (один Next.js-додаток)

Як на nmt.in.ua: **одна папка**, сторінки й API разом. Деплой — Vercel. MySQL лишається на VPS.

```
браузер → Next.js (Vercel: UI + /api) → MySQL `parta`
```

```
/
├── src/app/              сторінки App Router
├── src/app/api/          Route Handlers (той самий origin `/api`)
├── src/server/           Prisma, сервіси, JWT
├── src/components/
├── prisma/               schema + seed (migrate з репо не ганяти)
├── public/
├── .env                  JWT_SECRET, DATABASE_URL (не комітити)
├── README.md
└── .cursor/
    ├── PROJECT_CHAIN.md
    ├── ORIGINAL_PROMPT.md
    └── rules/project-chain.mdc
```

Окремих `frontend/`, `backend/`, `presentation/` **немає**. Express прибрано.

Клієнт ходить на `/api` того самого домену, якщо `NEXT_PUBLIC_API_URL` не заданий.  
Прод API: `https://parta-api.diesel.zp.ua/api`. Локально (`next dev`) — проксі `/backend-api`, бо CORS diesel пускає лише `https://moya-parta.vercel.app`.

Запуск: `npm run dev` → http://localhost:3000

Demo:
- Учень: `student@example.com` / `demo1234`
- Учитель: `teacher@example.com` / `demo1234`
- Код класу: `3B-DEMO`

## 7. Правила роботи над проєктом

- Не повертати батьківський/admin dashboard без явного запиту.
- Не робити leaderboard / рейтинги дітей.
- На **дошці класу** пости лише вчитель; учні — реакції + своя «Моя дошка».
- Чат лише всередині свого класу.
- Мова UI — проста, дружня, українською.
- Після кожної змістовної задачі — оновити цей файл.

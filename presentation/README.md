# Дерево продукту — Цифровий клас

Презентація для команди: карта екранів і можливостей MVP.

## Як відкрити

1. Відкрий файл [`index.html`](./index.html) у браузері (подвійний клік або «Open with Live Server»).
2. Керування: кнопки **Далі / Назад**, стрілки ← →, або меню зверху.
3. На слайді «Дерево» клікай по вузлах, щоб згортати / розгортати гілки.
4. Для PDF: у браузері **Друк → Зберегти як PDF** (усі слайди підуть окремими сторінками).

## Структура слайдів

| # | Слайд | Зміст |
|---|--------|--------|
| 0 | Старт | Ідея продукту, ролі MVP |
| 1 | Дерево | Головна → Учитель → Учень (інтерактив) |
| 2 | Вхід | Реєстрація вчителя / join учня |
| 3 | Учитель | Функції по підгілках |
| 4 | Учень | Функції по підгілках |
| 5 | Ланцюг | Від реєстрації до життя класу |

## Файли

- `index.html` — презентація
- `styles.css` — оформлення
- `app.js` — навігація слайдів і дерево

MVP · презентація команді

У кожного є своя парта.
У кожного є своє місце в класі.

Не електронний щоденник. Закритий цифровий світ класу для 1–4: спілкування, творчість, навчання, події й маленькі перемоги — без рейтингів між дітьми.

Ролі: учитель + учень Батьки лише допомагають на вході Без school admin у MVP

Огляд

Дерево проєкту

Від головної — гілка вчителя (створює клас) — від неї гілка учня (входить за кодом). Клацни вузол, щоб розгорнути.

  • Бренд і ідея: «своя парта в цифровому класі»
  • CTA: увійти / стати вчителем / приєднатись за кодом
  • Пояснює світ класу без вигляду «корпоративної LMS»

Головна · реєстрація

Що відбувається на вході

01

Головна `/`

  • Показує продукт і тон «цифрового класу»
  • Шляхи: Увійти · Я вчитель · У мене є код
02

Учитель `/register`

  • Імʼя, логін, пароль, аватар
  • Далі створює клас на дашборді
  • Отримує код + посилання `/join/КОД`
03

Учень `/join`

  • Батьки можуть допомогти ввести код (без кабінету)
  • Реєстрація привʼязує до класу й учителя
  • Onboarding → Моя парта
04

Увійти `/login`

  • Повернення в свій світ за роллю
  • Учитель → «Сьогодні», учень → «Моя парта»
Канон доступу: учитель створює клас → дає код/лінк → учень (або з допомогою батька) join. Немає окремого батьківського кабінету й school admin у MVP.

Гілка вчителя

Що може вчитель

📋 Сьогодні

  • Огляд: нові роботи, виконане, квест, подія
  • Бейджі «нове» на навігації
  • Швидкий перехід до завдань / подій / коду

🏫 Клас і запрошення

  • Створити клас (назва)
  • Код латиницею + лінк для учнів
  • Оновити код; переглянути склад класу

📝 Завдання

  • Створити / видалити домашнє
  • Повʼязати з тестом (за потреби)
  • Список завдань класу

🧪 Тести

  • Взяти з бази (напр. математика)
  • Створити свій тест
  • Видалити тест класу

✅ Перевірка

  • Переглянути відповідь учня
  • Коментар учителя
  • Прийняти / на доопрацювання / переробити тест

📅 Події

  • Створити з початком і кінцем
  • Після кінця: хто брав участь
  • Ревʼю + матеріали → пост на дошку

🛡️ Дошка

  • Пости учнів зʼявляються одразу
  • Учитель може приховати пост

💬 Чат

  • Чат усього класу
  • Особисті повідомлення з учнями

Гілка учня · від класу вчителя

Що може учень

🪑 Моя парта

  • Особистий «дім» у цифровому класі
  • XP, рівень, короткі завдання дня
  • Найближча подія, мета класу

🏫 Мій клас

  • Однокласники, учитель, мета
  • Дошка життя класу
  • Події класу

🎨 Дошка

  • Публікації одразу (без премодерації)
  • Реакції друзів
  • Своя творчість у спільному просторі

📚 Навчання

  • Домашні: виконати / доробити за коментарем
  • Тести з миттєвим фідбеком
  • Квести кроками + «що я пропустив?»

💬 Чат

  • Повідомлення всьому класу
  • Особисті з однокласником
  • Особисті з учителем

🏆 Перемоги і рюкзак

  • Досягнення без рейтингів
  • Стікери / нагороди в рюкзаку
  • XP лише накопичується

📅 Події

  • Бачить початок і кінець
  • Приєднується, поки подія триває
  • Бачить підсумок на дошці після ревʼю вчителя

🔔 Сповіщення

  • Нові завдання, чат, події, реакції
  • Бейджі на вкладках «що подивитись»

Як це зʼєднано

Ланцюг класу

  1. Учитель реєструється /register
  2. Створює клас назва · власний простір
  3. Ділиться кодом / лінком /join/КОД · латиниця
  4. Учень (з допомогою батька за потреби) join без батьківського кабінету
  5. Onboarding → Моя парта світ навколо дитини
  6. Життя класу крутиться разом дошка · чат · завдання · події · перемоги

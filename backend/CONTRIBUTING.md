# Внесок у backend-myclassroom

## Collaborators only

Pull request можуть відкривати **лише collaborators** репозиторію.

Щоб долучитись — попроси власника додати тебе як collaborator:
[https://github.com/tony-kobs/backend-myclassroom/settings/access](https://github.com/tony-kobs/backend-myclassroom/settings/access)

## Ревʼю перед merge

1. Створи гілку від `master`
2. Відкрий PR
3. Дочекайся **ревʼю й approve від власника** (`@tony-kobs`)
4. Merge робить власник **після** ревʼю

Прямий push у `master` для чужих змін заборонений. Force-push у `master` — ні.
